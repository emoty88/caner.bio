## Overview

Reqora is an AI-driven platform for e-commerce returns management and resale automation, built for Amazon sellers.

## Tech Stack

- **Backend:** Python, Django, Django REST Framework, Celery, RabbitMQ
- **AI Pipelines:** LangChain, LangGraph — automated product evaluation and pricing workflows
- **Frontend:** React, Redux, Material UI
- **Integrations:** Amazon Seller APIs (SP-API) for inventory and returns sync
- **Infrastructure:** Docker, AWS

## What it does

Sellers on Amazon deal with a constant stream of returned items. Reqora automates the evaluation, pricing, and resale workflow — reducing manual effort and recovering more revenue from returns.
